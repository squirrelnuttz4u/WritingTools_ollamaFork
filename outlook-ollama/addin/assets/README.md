# Add-in icons

These PNGs are **placeholder icons** generated by `generate_icons.py`: a solid
Fluent-blue background with white "AI" text. They exist so the manifest
validates and the ribbon button shows something recognisable during
development.

**Replace before production rollout** with icons that match your company's
brand guidelines. Deliver at these exact pixel sizes:

| File           | Size     | Used by |
| -------------- | -------- | ------- |
| `icon-16.png`  | 16x16    | Ribbon (small) |
| `icon-32.png`  | 32x32    | Ribbon (medium) |
| `icon-64.png`  | 64x64    | `IconUrl` (manifest root) |
| `icon-80.png`  | 80x80    | Ribbon (large) |
| `icon-128.png` | 128x128  | `HighResolutionIconUrl` |

## Regenerating the placeholders

```bash
pip install Pillow
python generate_icons.py
```

The script uses DejaVu Sans Bold on Linux and Arial Bold on Windows/Mac, and
falls back to Pillow's bitmap font if neither is installed (icons will still
render, just less pretty).
